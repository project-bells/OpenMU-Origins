# 05. สถาปัตยกรรมความปลอดภัยแบบเซิร์ฟเวอร์เป็นผู้ชี้ขาด (Server-Authoritative Security)

**โครงการ**: OpenMU-Origins & OpenMu-ClientMainS6E3  
**วันที่ตรวจสอบ**: 13 พฤศจิกายน 2569  
**สถานะการประเมิน**: **ผ่านเกณฑ์ระดับสมบูรณ์ (Zero Client Trust Enforced)**  
**หลักการสถาปัตยกรรม**: Server-Authoritative State Engine  
**ผู้ตรวจสอบ**: Senior Game Engine & Application Security Architect  

---

## 1. หลักการไม่เชื่อถือข้อมูลจากเครื่องลูกข่าย (Zero Trust Client Input)

ในเกม MMORPG ดั้งเดิมหลายเกม ไคลเอนต์มักได้รับอนุญาตให้คำนวณตำแหน่ง ดาเมจ หรือสถานะของตนเอง แล้วส่งผลลัพธ์มาบอกเซิร์ฟเวอร์ ซึ่งเปิดช่องให้ถูกโจมตีด้วยโปรแกรมโกง (Speed Hack, Range Hack, One-Hit Kill, Teleport)

ในสถาปัตยกรรมของ `OpenMU-Origins`:
- **เซิร์ฟเวอร์คือผู้ตัดสินชี้ขาดเพียงผู้เดียว (Single Source of Truth)**
- ไคลเอนต์ (`Main.exe`) มีหน้าที่เป็นเพียงส่วนแสดงผล (Display / Presentation Layer) และส่ง "คำขอการกระทำ" (Action Intents) เข้ามาเท่านั้น
- ข้อมูลสำคัญต่อไปนี้ **ไม่ได้รับอนุญาต** ให้ไคลเอนต์เป็นผู้กำหนด:
  1. **พิกัดและตำแหน่ง (Position & Coordinates)**: คำนวณและตรวจสอบระยะเดินจริงบนแผนที่
  2. **ความเร็วโจมตีและความเร็วเดิน (Movement & Attack Speed)**: คำนวณจากค่า Stat, ไอเทมที่สวมใส่, และบัฟบนเซิร์ฟเวอร์
  3. **ความเสียหายและเกราะป้องกัน (Damage & Defense)**: คำนวณผ่าน `AttributeSystem` ของเซิร์ฟเวอร์
  4. **คูลดาวน์สกิลและมานา (Skill Cooldown & Mana Cost)**: ตรวจสอบและหักมานาบนเซิร์ฟเวอร์
  5. **การครอบครองไอเทมและเงิน (Item Ownership & Currency)**: ตรวจสอบในฐานข้อมูลและหน่วยความจำของเซิร์ฟเวอร์

## 2. การควบคุมและตรวจสอบสถานะของผู้เล่น (Player State Machine Validation)

เซิร์ฟเวอร์เกมควบคุมสถานะของผู้เล่นผ่าน State Machine ใน `PlayerState`:

```
+--------------------+
|    EnteredWorld    | <----+
+---------+----------+      |
          |                 |
          | Open NPC / Trade| Close / Cancel
          v                 |
+---------+----------+      |
|  NpcDialogOpened   | -----+
|  or TradeOpened    |
+---------+----------+
          |
          | Confirm Trade
          v
+---------+----------+
| TradeButtonPressed |
+---------+----------+
          |
          | Commit & Reset
          v
+--------------------+
|    EnteredWorld    |
+--------------------+
```

### การป้องกันการส่งคำขอข้ามบริบท (Cross-Context Request Injection):
- ผู้เล่นไม่สามารถส่งคำขอที่ขัดกับสถานะปัจจุบันได้:
  - ขณะอยู่ใน `TradeOpened`: ไม่สามารถโจมตี, ใช้สกิล, เดิน, หรือเปิดคลังเก็บของได้
  - ขณะอยู่ใน `NpcDialogOpened`: ไม่สามารถเริ่มการเทรดกับผู้เล่นอื่นได้
  - ขณะตาย (`Dead`): ไม่สามารถย้ายไอเทมหรือใช้งานร้านค้าได้
  - หากได้รับแพ็กเกจที่ไม่สอดคล้องกับ State เซิร์ฟเวอร์จะปฏิเสธคำขอทันที และเพิ่ม Risk Points ในระบบ Anti-Cheat

## 3. การตรวจสอบขอบเขตและขนาดของแพ็กเก็ต (Packet Boundary & Length Guard)

ใน `PacketHandlerPlugInContainer.cs`:
- ทุก Opcode มีการกำหนดขนาดความยาวขั้นต่ำและโครงสร้างฟิลด์ที่ชัดเจน
- หากแพ็กเกจสั้นกว่าขนาดขั้นต่ำ (Truncated Packet) หรือยาวเกินกำหนด (Buffer Overflow Attempt) ระบบจะปฏิเสธและตัดการเชื่อมต่อทันที
- การ Deserialize ใน `MUnique.OpenMU.Network.Packets` ทำงานบน `ReadOnlySpan<byte>` แบบ Type-Safe ไร้ Unsafe Pointer Arithmetic

## 4. ตารางประเมินผลการบังคับใช้สิทธิ์ของเซิร์ฟเวอร์แยกตามระบบ

| ระบบเกมเพลย์ | การทำงานฝั่ง Client | การบังคับใช้ฝั่ง Server | ผลการประเมิน |
|---|---|---|---|
| **การเดินและการเคลื่อนที่** | ส่งพิกัดและทิศทางที่ต้องการเดิน | ตรวจสอบระยะก้าวและสิ่งกีดขวางบน Map Grid | **ปลอดภัย**: วาร์ปเกินจริงจะถูกดึงกลับ |
| **การใช้สกิลและการโจมตี** | ส่ง Animation และเป้าหมาย | ตรวจสอบระยะห่าง, คูลดาวน์, และความถี่สกิล | **ปลอดภัย**: ยิงสกิลรัวเกิน Stat จะถูกบล็อก |
| **การย้ายไอเทม** | ลากไอเทมบนหน้าจอ UI | ตรวจสอบช่องว่างในกระเป๋าและประเภท Storage | **ปลอดภัย**: ย้ายของข้ามคลังปลอมไม่ได้ |
| **การซื้อขายกับ NPC / ร้านค้า** | คลิกซื้อไอเทม | ตรวจสอบราคากลางและหักเงินจริง | **ปลอดภัย**: ปลอมราคาจาก Client ไม่ได้ |
| **การเพิ่มค่า Stat** | เลือกแต้มที่ต้องการเพิ่ม | ตรวจสอบแต้มคงเหลือจริงก่อนบันทึก | **ปลอดภัย**: ส่งค่าล้นหรือติดลบจะถูกตีกลับ |

---

## 5. บทสรุปการประเมิน
สถาปัตยกรรม Server-Authoritative ของ OpenMU-Origins ปฏิบัติตามมาตรฐานความปลอดภัยของเกมออนไลน์สมัยใหม่อย่างเคร่งครัด ตัดช่องทางและโอกาสในการใช้โปรแกรมโกงปรับแต่งค่าใน Client ได้อย่างมีประสิทธิภาพ
